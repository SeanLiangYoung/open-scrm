# 脚本命令速查表

## 🚀 启动服务

### 启动所有服务
```bash
pnpm run start:all
```

### 启动单个服务

以下端口为各服务 **`mw dev` / 容器内监听** 约定（与 `code/docs/迭代计划-E2E.md` 一致）。命令均为 Windows PowerShell 包装脚本。

```bash
pnpm run start:gateway      # API 网关 (7000)
pnpm run start:auth         # 认证服务 (7001)
pnpm run start:customer     # 客户服务 (7002)
pnpm run start:acquisition  # 获客服务 (7003)
pnpm run start:operation    # 运营服务 (7004)
pnpm run start:asset        # 素材服务 (7005)
pnpm run start:analytics    # 分析服务 (7006)
pnpm run start:integration  # 集成服务 (7007)
pnpm run start:message      # 消息服务 (7008)
pnpm run start:finance      # 财务服务 (7009)
```

## 🛑 停止服务

### 停止所有服务
```bash
pnpm run stop:all
```

### 停止单个服务
- 关闭服务窗口，或在窗口中按 `Ctrl+C`

## 🔍 检查状态

### 检查所有服务状态
```bash
pnpm run check:services
```

### 检查单个服务
```bash
# 访问健康检查接口（网关 7000；Docker Compose 宿主机映射常为 17000）
curl http://localhost:7000/health   # 网关
curl http://localhost:7001/health    # 认证（直连）
# ... 其他服务见端口对照表
```

## 🧪 测试命令

### 完整测试（编译 + 类型检查）
```bash
pnpm run test
```

### 仅编译测试
```bash
pnpm run test:build
```

### 仅类型检查
```bash
pnpm run test:type
```

### 生成测试报告
```bash
pnpm run test:report
```

### 详细输出测试
```bash
pnpm run test:verbose
```

### 单元测试（Vitest）

在 `code/` 目录执行：

```bash
pnpm run test:unit
```

### E2E（Playwright）

在 `code/` 目录执行：

```bash
pnpm run test:e2e              # 完整流程（需网关、前端等）
pnpm run test:e2e:api          # API：sprint1-api + sprint2-integration
pnpm run test:e2e:sprint2      # 仅 Sprint 2 经网关探测
```

## 💾 数据库管理（PostgreSQL）

### 初始化数据库
首次启动 `docker compose` 中的 `postgres` 时会自动执行 `scripts/init-db.pg.sql`。手动示例：

```bash
PGPASSWORD=root123 psql -h localhost -U postgres -d scrm_dev -f scripts/init-db.pg.sql
```

### 启动 Docker 服务
```bash
docker-compose up -d
```

### 停止 Docker 服务
```bash
docker-compose down
```

## 📝 快速开发流程

```bash
# 1. 启动依赖服务
docker-compose up -d

# 2. 启动需要的微服务
pnpm run start:gateway
pnpm run start:auth
pnpm run start:customer

# 3. 开发代码...

# 4. 运行测试
pnpm run test

# 5. 停止服务
pnpm run stop:all
# 或关闭服务窗口
```

## 🆘 故障排查

### 端口被占用
```bash
# 检查端口占用
netstat -ano | findstr "7001"

# 停止所有服务
pnpm run stop:all
```

### 服务启动失败
```bash
# 检查配置
# 1. 确认 .env 文件存在
# 2. 确认数据库已启动
# 3. 确认 Redis 已启动

# 检查服务状态
pnpm run check:services
```

### 依赖问题
```bash
# 重新安装依赖
rm -rf node_modules
pnpm install
```
