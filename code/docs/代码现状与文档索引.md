# 代码现状与文档索引

> 本文描述 `code/` 目录的**当前工程事实**与文档入口，便于与仓库根目录 `docs/` 中的规格、历史计划区分。

## 1. 仓库布局

| 路径 | 内容 |
|------|------|
| `code/` | pnpm + Turborepo：微服务、共享包、前端应用、E2E、Dockerfile |
| `docs/`（仓库根） | 产品/协作索引、[开发计划.md](../../docs/开发计划.md)、指南 |
| `code/docs/` | **可执行迭代计划**、Harness、实现计划草稿 |

## 2. 运行时事实（开发环境）

| 项 | 说明 |
|----|------|
| 数据库 | **PostgreSQL**；Docker 常将宿主机 **5433** 映射到容器 **5432**（见 `code/docker-compose.yml`） |
| 初始化 | 新数据卷首次启动执行 `code/scripts/init-db.pg.sql` |
| Redis | 默认 `localhost:6379`（与 Compose 一致） |
| 网关 | 服务监听 **7000**；Compose 将宿主机 **17000** → 容器 **7000**（避免本机 7000 冲突） |
| 微服务端口 | gateway **7000**，auth **7001**，customer **7002** … finance **7009**（统一表见 [迭代计划-E2E.md](./迭代计划-E2E.md) §1.1；**路径→上游** 见 [facts/gateway-routes.md](./facts/gateway-routes.md)） |
| 前端 | admin-platform **3001**，operation-platform **3003**，official-website **3010**（Sprint 6）；代理目标由 `VITE_GATEWAY_URL` 配置 |

## 3. 测试与质量门禁

| 命令 | 作用 |
|------|------|
| `pnpm test:unit` | Vitest（shared-utils、gateway、auth、integration-service 等） |
| `pnpm test` | `scripts/test/full-test.sh`：单元测试 + 包构建 + type-check + lint + 全服务 build |
| `pnpm test:e2e` | `e2e/run-full-e2e.sh`：需网关可达 + 前端 |
| `pnpm test:e2e:sprint2` | 仅 Sprint 2 API E2E（`e2e/run-sprint2-api.sh`） |
