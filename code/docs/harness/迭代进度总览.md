## 本轮（S2）交付（归档）

- **企微标准验签**：`verifyWeworkMsgSignature(token, timestamp, nonce, cipher, msgSignature)`（密文参与 SHA1）。
- **经网关回调**：`GET|POST /api/v1/integration/wework/callback`；`bodyParser` 支持 `text/xml`。
- **种子数据**：`init-db.pg.sql` 插入开发用 `wework_config`（与单测 / E2E 常量一致）。
- **文档**：[Sprint2-功能开发测试计划.md](./Sprint2-功能开发测试计划.md) 全勾选；[本地启动与验证-Sprint2.md](./本地启动与验证-Sprint2.md) 补充回调与旧卷 SQL 说明。

## 本轮（S3）交付

- **幂等模型**：`message_log.idempotency_key` + 部分唯一索引；`normalizeIdempotencyKey` / `resolveIdempotentReplay`；`MessageSendService.sendMessage` 预查重放与并发 `23505` 处理。
- **经网关 API**：`MessageApiController` — `POST /api/v1/messages/send`（`Idempotency-Key` 头优先）、`GET /api/v1/messages/logs/:id`。
- **Mock 通道**：`messageType: 2`（站内通知）用于开发与 E2E，无外部渠道依赖。
- **测试**：`message-service` Vitest；Playwright `sprint3-messages.spec.ts`；`pnpm test:e2e:sprint3` / `run-sprint3-api.sh`。
- **文档**：[Sprint3-功能开发测试计划.md](./Sprint3-功能开发测试计划.md)、[本地启动与验证-Sprint3.md](./本地启动与验证-Sprint3.md)。

## 本轮（S4）交付

- **路径对齐**：analytics HTTP 前缀改为 **`/api/v1/analytics`**，与网关 `/api/v1/analytics/*` 转发一致。
- **日聚合**：`DailyAggregationService` 从 OLTP upsert `daily_stat`；`DailyStatAggregationJob`（cron `0 3 * * *`）；`POST /jobs/aggregate-daily` 手动触发当前租户。
- **查询**：`GET /summary?startDate=&endDate=`；`getOverview` 按日历日查 `daily_stat`；区间汇总纯函数 + Vitest。
- **前端**：`operation-platform` 仪表盘增加「聚合看板」区块（先聚合再读 overview）。
- **文档 / E2E**：`Sprint4-*`、根 `docs/services/analytics-service/README.md` 路径更新；`sprint4-analytics.spec.ts`。

## 本轮（S5）交付
