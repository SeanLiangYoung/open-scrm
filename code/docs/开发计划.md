## 二、开发计划

### Phase 0：基础修复（优先级 P0）

> 目标：消除所有基础配置问题，让所有后端服务能正确启动和通信

| 任务 | 描述 | 预期产出 |
|------|------|---------|
| 0.1 统一端口映射 | 将所有服务端口改为架构图定义值 | 所有 config.default.ts 端口一致 |
| 0.2 统一 DB 凭证 | 所有服务统一使用 root/root123/scrm_dev | 所有服务可连接数据库 |
| 0.3 修复密码哈希 | 重新生成 Admin@123 的 bcrypt 哈希 | 默认管理员可正常登录 |
| 0.4 修复 ESLint | 安装缺失依赖，修复配置 | pnpm lint 通过 |
| 0.5 Linux 测试脚本 | 将 .ps1 脚本转为 .sh + 更新 package.json | pnpm test 在 Linux 可执行 |

### Phase 1：核心后端完善（优先级 P0）

> 目标：完善网关和认证服务，使 API 层可用

| 任务 | 描述 | 预期产出 |
|------|------|---------|
| 1.1 完善 gateway-service | 实现 HTTP 代理路由转发 | 所有 /api/v1/* 请求正确转发 |
| 1.2 完善 auth-service | 添加用户 CRUD、角色管理 | 完整的用户和权限管理 API |
| 1.3 服务启动验证 | 确保所有10个服务可正常启动 | 全部健康检查通过 |

### Phase 2：管理平台前端（优先级 P0）

> 目标：搭建 admin-platform，实现登录和基础框架

| 任务 | 描述 | 预期产出 |
|------|------|---------|
| 2.1 项目初始化 | Vue3 + Vite + Element Plus + Pinia + Router | 可运行的前端项目 |
| 2.2 登录页面 | 用户名/密码登录，Token 管理 | 可登录系统 |
| 2.3 主布局框架 | 侧边栏 + 顶栏 + 内容区 | 完整的后台管理布局 |
| 2.4 仪表盘页面 | 数据概览卡片 + 图表 | 首页可视化 |

### Phase 3：运营平台前端（优先级 P1）

> 目标：搭建 operation-platform，实现客户管理和 SOP

| 任务 | 描述 |
|------|------|
| 3.1 项目初始化 | Vue3 + Vite + Element Plus |
| 3.2 客户管理 | 客户列表、详情、标签管理 |
| 3.3 SOP 管理 | SOP 模板创建、执行 |
| 3.4 数据看板 | 运营数据图表 |

### Phase 4：更多功能（优先级 P2）

> 目标：完善各服务的高级功能

| 任务 | 描述 |
|------|------|
| 4.1 获客模块完善 | 渠道活码、内容发布 |
| 4.2 消息推送 | 模板消息、群发 |
| 4.3 数据分析 | BI 看板、报表导出 |
| 4.4 移动端 | UniApp 项目搭建 |
